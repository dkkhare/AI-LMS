# AI-LMS

AI-LMS is a planned multi-tenant learning management system for institutions in India, Europe, and the United States.

The platform will use:

- Laravel/PHP backend
- React and TypeScript web applications
- React Native student application
- Amazon Web Services infrastructure
- MySQL
- LiveKit for live classes
- SCORM 1.2/2004 and Tin Can/xAPI
- Teacher-verified AI-assisted content and analytics

Development documentation and project scaffolding are being prepared through reviewed pull requests.
